# Генератор случайных паролей (Diceware)

Многоязычная реализация генератора парольных фраз методом Diceware.  
Генерирует надёжные пароли из случайных слов, взятых из стандартного словаря (7776 слов).  
Поддерживает настройку количества слов, разделителя, добавление цифр и спецсимволов, расчёт энтропии.

## Особенности
- Генерация парольной фразы из N случайных слов (по умолчанию 6).
- Встроенный словарь Diceware на английском языке (из 7776 слов).
- Возможность использования пользовательского словаря (файл с одной колонкой).
- Настраиваемый разделитель между словами (пробел, дефис, подчёркивание и др.).
- Добавление цифр и/или специальных символов в конец пароля.
- Автоматическое преобразование регистра (заглавная первая буква, все заглавные).
- Расчёт энтропии парольной фразы в битах.
- Сохранение сгенерированного пароля в файл.
- Вывод в различных форматах (текст, JSON).
- Поддержка аргументов командной строки для автоматизации и скриптов.

## Установка и запуск
Для каждого языка требуются соответствующие инструменты и зависимости.

### Запуск на разных языках

1. **Python**  
   Установка: не требуется дополнительных библиотек (используется стандартная библиотека).  
   Запуск: `python diceware.py --words 6 --separator "-" --digits --symbols`

2. **JavaScript (Node.js)**  
   Установка: `npm install commander`  
   Запуск: `node diceware.js --words 6 --separator "-" --digits --symbols`

3. **Go**  
   Установка: модулей не требуется.  
   Запуск: `go run diceware.go --words 6 --separator "-" --digits --symbols`

4. **Rust**  
   Добавьте `rand` и `clap` в `Cargo.toml`.  
   Запуск: `cargo run -- --words 6 --separator "-" --digits --symbols`

5. **Java**  
   Используйте стандартную библиотеку и Gson (опционально).  
   Сборка: `javac -cp gson.jar Diceware.java`  
   Запуск: `java -cp .;gson.jar Diceware --words 6 --separator "-"`

6. **C# (.NET Core)**  
   Установка: `dotnet add package Newtonsoft.Json`  
   Запуск: `dotnet run -- --words 6 --separator "-"`

7. **C++ (Linux)**  
   Требуется компилятор с C++11 и библиотека `nlohmann/json` (опционально).  
   Сборка: `g++ -std=c++11 -o diceware diceware.cpp`  
   Запуск: `./diceware --words 6 --separator "-"`

8. **Kotlin (JVM)**  
   Используйте стандартную библиотеку и Gson.  
   Сборка: `kotlinc -cp gson.jar Diceware.kt`  
   Запуск: `kotlin -cp .;gson.jar DicewareKt --words 6`

## Использование

Общие аргументы (везде, где поддерживается):

- `--words <число>` – количество слов в парольной фразе (по умолчанию 6).
- `--separator <строка>` – разделитель между словами (по умолчанию пробел).
- `--digits` – добавить две случайные цифры в конец.
- `--symbols` – добавить два случайных спецсимвола в конец.
- `--capitalize` – сделать первую букву каждого слова заглавной.
- `--uppercase` – все буквы заглавные.
- `--dictionary <путь>` – путь к файлу пользовательского словаря (по одному слову на строку).
- `--output <файл>` – сохранить пароль в файл.
- `--json` – вывести результат в формате JSON.
- `--entropy` – показать энтропию парольной фразы.

Пример (Python):
```bash
python diceware.py --words 8 --separator "_" --digits --symbols --capitalize --entropy --output password.txt
